# Compose UI Design System

Reusable Kotlin-first Jetpack Compose design system for Android apps.

## What is included

- Semantic theme tokens for colors, spacing, motion, typography, and icons.
- Material 3-backed components with slot APIs and state-hoisted inputs.
- Catalog and sample apps for browsing and consumer-like validation.
- Dokka API docs and MkDocs guide content.
- Startup macrobenchmark and baseline profile scaffold for sample flows.

## Current status

The library is preparing for `1.0.0`. The API should be treated as stabilizing until the final release tag is cut.

## Artifacts

GitHub Actions publishes the catalog APK, sample APK, benchmark APK, component screenshots, Compose compiler reports, and docs site artifacts from the CI workflow.
